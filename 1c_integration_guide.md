# Модуль интеграции с ERP-системами (1С / МойСклад)

Данный модуль позволяет дистрибьюторам AutoTerra автоматически синхронизировать остатки своих складов с платформой с помощью внешних учетных систем. 

## Для Дистрибьютора: Как настроить интеграцию

1. Откройте приложение AutoTerra и войдите под аккаунтом Дистрибьютора.
2. В нижнем навигационном меню перейдите на вкладку **"1С"** (Интеграция 1С).
3. Нажмите кнопку **"СГЕНЕРИРОВАТЬ НОВЫЙ КЛЮЧ"**.
4. Скопируйте появившийся ключ (токен) и передайте его вашему 1С-программисту или системному администратору.
5. На этом же экране вы будете видеть **"Журнал синхронизации"** — логи всех попыток обмена данными с платформой (успешных и ошибочных).

---

## Для 1С-программиста: API Документация

Для обновления остатков необходимо отправлять POST-запрос на сервер AutoTerra.

### Endpoint
`POST /api/integration/erp/stock-update/`

*(Абсолютный URL зависит от текущего домена сервера, например: `https://api.autoterra.ru/api/integration/erp/stock-update/`)*

### Авторизация (Headers)
Вы должны передать уникальный токен дистрибьютора в заголовке `X-Integration-Token`.
Опционально поддерживается стандартный заголовок `Authorization: Bearer <TOKEN>`.

```http
Content-Type: application/json
X-Integration-Token: ВАШ_СГЕНЕРИРОВАННЫЙ_КЛЮЧ
```

### Формат данных (Body)
Система ожидает плоский JSON-массив объектов. У каждого объекта должны быть заполнены поля `sku` (артикул) и `quantity` (количество). Поле `price` (цена) — опциональное.

```json
[
  {
    "sku": "LAK-77-01",
    "quantity": 150,
    "price": "2400.00"
  },
  {
    "sku": "GRN-77-02",
    "quantity": 0
  }
]
```

### Пример запроса (cURL)

```bash
curl -X POST https://domain.com/api/integration/erp/stock-update/ \
  -H "Content-Type: application/json" \
  -H "X-Integration-Token: f4a8c9b2d1e..." \
  -d '[
    {"sku": "LAK-01", "quantity": 10},
    {"sku": "LAK-02", "quantity": 0, "price": 1000}
  ]'
```

### Ответ сервера (Responses)

**Успех (200 OK):**
```json
{
  "status": "success",
  "updated": 2,
  "errors": []
}
```

**Частичный успех (200 OK, но есть ошибки):**
*(Например, передан несуществующий артикул)*
```json
{
  "status": "error",
  "updated": 1,
  "errors": [
    "Product with sku 'LAK-999' not found"
  ]
}
```

**Ошибка авторизации (401 Unauthorized):**
```json
{
  "detail": "Invalid or inactive token"
}
```

*Все попытки синхронизации (даже неудачные) логируются в базе данных AutoTerra и отображаются в кабинете дистрибьютора.*
