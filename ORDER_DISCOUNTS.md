# Отображение скидок

ProductData поддерживает discountPercent, effectiveDiscountPercent, hasDiscount
и прежние basePrice/personalPrice/priceSource. Каталог (compute/isolate) и product
quote используют один parser; отсутствующие поля старого API получают безопасные
значения. Итоговые цены из процентов во Flutter не вычисляются.

ClientProductPrice используется в каталоге оформления, карточке товара, выбранных
позициях и product picker. Показывает серверную цену, фактический процент и
зачёркнутый прайс только при реальной разнице цен. ShopSalePrice и его markup
остаются отдельным отображением цены продажи магазина.

Изменение состава корзины запрашивает POST /orders/quote/ с debounce 250 мс.
Ответ старого запроса не может перезаписать результат нового состава корзины.
Во время расчёта итог не выдумывается; при ошибке доступен повтор, отправка
заблокирована до получения quote. Перед отправкой выполняется обновление цен
и quote, а backend при создании независимо пересчитывает всё ещё раз.

OrderDiscountSummary показывает сумму до объёмной скидки, реальную экономию,
серверный итог, текущую и следующую ступень и серверный progress. Формулы лестницы
во Flutter нет. Бонусы и наличная оплата используют итог из quote. На максимуме
стимул докупить скрыт. Для договорных товаров дополнительная скидка не обещается.

Формы персональной и брендовой скидок допускают 0–40%, максимум два знака после
запятой. 40.01, 50, 100, NaN и Infinity сохранению не подлежат.

Backend необходимо обновить до выпуска этого клиента: без нового quote endpoint
приложение покажет ошибку расчёта и не даст отправить неподтверждённый итог.

На экране корректировки оператором локальный предварительный итог удалён:
при изменениях показано сообщение о серверном пересчёте, после отправки
используется сохранённый итог заказа. Новый предварительный quote для операторов
не вводился; POST /orders/quote/ остаётся клиентским endpoint.
